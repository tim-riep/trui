# TRUI

TRUI is a library of React components for business applications: inputs, forms, tables,
dialogs, page layouts and the building blocks of a home page with tiles. The components
share one calm, dense appearance for people who work with data all day.

- **Theming** through design tokens as CSS custom properties, with a light and a dark theme
  and two densities.
- **Exact values**: decimals are canonical strings, `null` and `""` are different values.
- **Localized** formatting and input through `Intl`, text packages in English and German,
  right-to-left layout.
- **Accessible**: keyboard operation, ARIA roles and visible focus, targeting WCAG 2.2 AA.
- **Shareable** under module federation: all global state lives in React contexts.
